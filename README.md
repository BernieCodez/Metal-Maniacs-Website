## Contributing
If you would like to contribute to the website, here is an in depth
tutorial on how to do so!

### Setting Up
In github, at the top of this repository you will see a green "Code" button. Clicking it will pop up a small menu. Click on the "Codespace" tab followed by the green "Create codespace on main" button. This codespace is where you will make all of your modifications. Wait for everything to finish loading.

### Testing
On the left side, you will see all the website files. You are free to modify them as you wish, but be careful 🙏. To see the website, open up the terminal by pressing `Ctrl + J`. Navigate to the "terminal" tab then type in:
```
npm start
```
A page will open up, asking if you trust this website. Since it is YOURS, you can safely proceed.

If the website page does NOT open up go to the "ports" tab and `Ctrl + Click` on the link under the "Forwarded Address"

To see your changes, all you have to do is refresh the page! 

If you are finished with editing or want to close the website for whatever reason, navigate to the "terminal" tab and press `Ctrl + C` to terminate.

### Pushing Changes
If you want to update your changes to the main website (being hosted), then you have to commit, then push your changes. Github makes this process very easy.

On the very left, their should be a series of icons. One of them looks like a merge and hovering over it will say "Source Control..."

At the very top, type in your commit message/name or summary of change, then press the blue "commit" button. Then simply press the "push" button. All done!
